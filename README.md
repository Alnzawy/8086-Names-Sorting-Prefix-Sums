# Names Sorting and Numbers Prefix Sums

## Overview
A collaborative academic project developed as part of the CCS 3310 – Computer Architecture & Assembly Language course at the Islamic University of Madinah during the first semester of the 2023–2024 academic year.

The project focuses on implementing data processing operations using Assembly Language in the EMU8086 emulator. It allows users to enter names and numbers, classify the input data, sort names in ascending order, and calculate prefix sums for numerical values.

## Key Features
- Interactive menu-driven interface.
- User-defined number of input items and data lengths.
- Input validation to distinguish alphabetic names from numeric values.
- Display of entered items in their original order.
- Classification of names and numbers.
- Ascending alphabetical sorting of names.
- Calculation of prefix sums for numerical values.
- Display of processed results.

## Technologies & Tools
- Assembly Language (8086)
- EMU8086 Emulator
- Computer Architecture Concepts
- Data Processing Algorithms
